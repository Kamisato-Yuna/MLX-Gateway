# 交互与开源准备验证

日期：2026-09-06。环境：Apple Silicon，Xcode 27 beta 6（27A5252f），Swift 6 语言模式。此记录是本次开发的验证范围，不代表所有模型或客户端均已验收。

| 问题/范围 | 修改与验证结果 |
| --- | --- |
| 模型写死为维护者本机的三个型号 | 从用户模型目录读取 config.json；测试覆盖嵌套同名目录、单个模型目录、空目录、无效配置、符号链接跳过和路径不泄露。 |
| MLX 环境不能配置 | 原生文件夹选择器与独立 Python/模型路径输入可用；无效目录拒绝保存，取消恢复原配置。 |
| 重开设置覆盖独立模型目录 | 已修复同值 TextField 回写触发联动；实际保存空目录、重开设置仍保留，再恢复原目录。 |
| 空列表造成无意义启动 | 显示目录选择引导、禁用启动；实际 API 模型列表同步为空。 |
| 地址复制没有结果反馈 | 实际点击后显示“已复制”；可直接复制模型 ID。 |
| 自动滚动与日志更新混在一起 | 关闭“跟随最新”后手动滚动仍能看到本次启动与推理日志。 |
| 所选模型与当前模型状态混淆 | 模型运行时选择另一模型，界面明确显示当前模型和“所选模型尚未启动”提示。 |
| 启停与切换 | 界面启动文本模型，再切换至视觉后端，确认新模型就绪；⌘. 停止并恢复操作。 |
| 设置可访问性 | ⌘, 可打开；运行时可查看但不能保存，端口相同会显示明确错误。 |
| Swift 6 | Debug 开发签名构建通过；服务与扫描 fixture 共 72 项检查通过。 |
| Icon Composer | 原创三层 SVG，检查默认、深色、单色外观；Xcode 成功编译为应用图标。 |
| 签名顺序 | 将提前手动签名改为 Xcode 原生签名；`codesign --verify --strict` 通过，实际 TeamIdentifier 与证书 OU 一致。 |
| 开源文件 | MIT、双语 README、贡献/安全说明、Issue/PR 模板、CODEOWNERS、Actions 和 Dependabot；本地文档链接与 diff 检查通过。 |

实际文本推理：在界面手动启动 Qwen3 Coder 后，经 `POST /v1/responses` 输入“只回复：你好”，得到 `status=completed`、文本“你好！”、输入 12 / 输出 3 tokens。随后实际切换到 Qwen3.6 35B 的 `mlx_vlm` 后端并确认就绪、停止；未在本轮为所有模型执行完整推理矩阵。

本地 `build/` 中的构建日志、原始推理返回和测试产物不提交。凭据模式检查覆盖公开前的当前文本文件和历史提交，未发现所检查的密钥模式；这不等于全面安全审计。没有创建正式 Release、分发安装包或进行公证。
