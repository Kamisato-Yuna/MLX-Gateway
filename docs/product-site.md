# 产品展示与发布页

线上地址：<https://kamisato-yuna.github.io/MLX-Gateway/>。

## 维护

`site/` 是零构建依赖的静态站点。文案与结构在 `index.html`，视觉、响应式和减弱动态效果在 `styles.css`，演示、复制及 Release 查询在 `app.js`。

本地预览：

```sh
python3 -m http.server 4176 --bind 127.0.0.1 --directory site
```

打开 `http://127.0.0.1:4176/`。网页仅模拟选择、启动、停止和连接流程，不向本机模型服务发送请求。

`.github/workflows/pages.yml` 使用 GitHub 官方 Pages Actions，只上传 `site/`。`main` 上的站点修改或手动执行 Product Pages 工作流会更新页面。仓库 Pages 的构建来源需为 GitHub Actions。

## 发布信息

页面展示 0.3.0 的音频转写、独立图像生成和可选常驻服务设置。音频已完成原生界面与 FChat 转写验收。图像已通过隔离测试，真实出图因可用内存不足仍待验收；页面链接到该版本的验证记录。

下载按钮固定指向已验证的 0.3.0 ZIP。静态文案说明其 Developer ID 签名、Apple 公证与已附加的公证票据。浏览器另查询 GitHub 最新正式 Release，仅更新最新版本链接，不覆盖固定版本及其公证信息。查询失败时保留已知版本链接，并显示同步失败说明。禁用 JavaScript 时，下载、发布说明与源码入口仍可使用。

发布新版本时，按实际产物更新下载链接、版本、日期、大小、公证说明及 `site/update.json`。Release 的存在本身不证明签名或公证。

## 视觉与素材

沿用原有 `docs/images/app-icon.png`。主视觉 `site/assets/hero-glass.webp` 由内置 imagegen 生成，再转换成 WebP；表现三层玻璃、本地芯片与统一网关。装饰图配合 CSS 浮动与指针倾斜，所有文字与操作均为原生 HTML。网站没有 Three.js、追踪脚本或远程字体依赖。

生成提示概要：冰白 `#f5f8ff`，青蓝与浅紫光场，三层透明圆角玻璃、蓝色网关与薄荷绿芯片、细椭圆轨道；保留完整构图，去除文字，四边淡化至背景色。

页面沿用原有主视觉和玻璃窗口。能力区用三列说明音频、图像和常驻服务，窄屏改为单列。后续为三步演示与版本发布区。产品说明按 README 和版本验证记录校正，图标沿用真实品牌。

## 本轮验证范围

2026-10-17 在 Codex 内置浏览器完成本轮页面验收：1280 × 720 桌面、390 × 844 和 320 × 740 移动视口均无横向溢出，所有图片加载成功。已检查能力与发布锚点、演示启动和停止、加载期间切换连接步骤及复制成功反馈。版本查询成功后，0.3.0 公证文案仍保留；临时阻断查询后，固定下载和发布说明仍可用。减弱动态效果下页面内容可见。测试结束后恢复正常网络和视口。

本轮只更新静态网页，未启动模型或执行真实图像生成。以下为此前页面的验收记录。

测试只覆盖页面：桌面与移动布局、锚点、选择/启动/停止/快速切换、复制反馈、外链、发布信息及减弱动态效果。网页演示不构成 macOS 应用或真实 MLX 模型验收。

2026-09-06 在 Codex 内置浏览器验证了 1505 × 1045 桌面、390 × 844 与 320 × 740 移动视口，无横向溢出；所有页面图片成功加载。已检查启动完成、停止、加载期间切换到连接步骤不会被延迟回调覆盖；通过浏览器读取剪贴板确认复制出的克隆命令正确。

Release 验证包括真实无版本状态，以及临时模拟网络失败和新版本响应；模拟仅用于浏览器验证，随后重新加载恢复。减弱动态效果开启时，浮动动画关闭、滚动变为即时、内容仍可见。

视觉对照通过 `view_image` 检查概念与浏览器截图，比较了标题与 CTA 文案、双栏构图、字体层级、冰蓝配色、玻璃素材与白色边缘、间距和移动端顺序。首屏标题、导航、CTA、平台文案一致；说明文本按真实产品范围修正，品牌使用仓库原图，演示额外标明模拟边界。主视觉使用生成资产结合 CSS 空间动效，未使用 WebGL。页面按概念的布局和视觉系统完成实现，无待修复的重大视觉问题。
